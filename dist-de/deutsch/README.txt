DREAD DAWN - GERMAN LANGUAGE PACK
=================================
Makes Dread Dawn German: menus, items, building and crafting, hints, story dialogs and
cutscenes. The game's original files are not changed. (German instructions: LIESMICH.txt)

INSTALLATION
1. Unpack this package into the Dread Dawn folder, i.e. where the folder "Word" is.
   Afterwards it contains "Dread Dawn DEUTSCH.bat" and the folder "deutsch".
2. Keep the game language set to "English": the pack replaces the English texts.

PLAYING
- Single player: start "Dread Dawn DEUTSCH.bat".
- Co-op: start "Dread Dawn COOP.bat" as usual. With the pack installed the co-op game is German
  too, including the co-op messages. Each player sees the language installed on his own PC.
- Co-op in English despite the pack: add  -Dcoop.lang=en  after coop-mod.jar" in
  "Dread Dawn COOP.bat".

GOOD TO KNOW
- On the first start the pack builds the adapted game once (deutsch\cache), again after a
  game update.
- Texts that exist only as pictures in the game (e.g. the keyboard help) stay English.
- Removing: delete "Dread Dawn DEUTSCH.bat" and the folder "deutsch".
